# 중요한 선택의 사람 말

아직 기록 없음. 실제 선택·이유 원문 또는 기존 원문 위치만 기록한다. AI 추천은 사람 이유로 쓰지 않는다. 모든 카드를 채우도록 요구하지 않는다.

## 일곱 칸

채울 의무는 없다. 사용자가 말하지 않은 칸은 빈칸으로 둔다.

| 칸 | 내 말 | 담당자에게 묻는 꼴 |
|---|---|---|
| 1. 문제 한 문장 |  | 지난번에 가장 곤란했던 일이 뭐였나요? |
| 2. 좋음의 정의 |  | 두 안이 있으면 무엇을 보고 고르시나요? |
| 3. 못 깨는 것 |  | 이걸 어기면 무슨 일이 생기나요? |
| 4. 기존 숫자 |  | 지금 방식으로는 얼마나 나오나요? |
| 5. 계산 방식 |  | 답이 조금 나빠도 빠른 쪽이 좋나요? |
| 6. 서비스 경계 |  | 결과를 누가 언제 확정하나요? |
| 7. 증거 |  | 이 결과를 어떻게 믿으실 건가요? |
