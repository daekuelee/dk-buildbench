# 데이터 분석: 값의 의미에서 판단까지

언제: 제공 자료가 요구·계산·표시·선택의 근거일 때. 분석 도구를 돌리는 것 자체를 목표로 삼지 않는다.

## 최소 지도

한 행의 의미·단위 → 값과 분포 확인 → 누락·중복·범위 확인 → 묶기·연결·계산 → 요구에 대한 해석.

## 사람이 판단할 것

- 한 행은 사람·사건·시간 구간 중 무엇이며, 값의 단위와 기준 시점은 무엇인가.
- 누락은 0인지 미확인인지, 중복은 오류인지 실제 반복인지. 자료만으로 모르면 질문·가정으로 둔다.
- 무엇을 기준으로 묶거나 합치는지, 행이 늘거나 빠지는 이유는 무엇인지.
- 이 확인 때문에 화면·계산·방법 선택이 어떻게 바뀌는지.

## 작은 적용

가상의 같은 그룹 값 `10, 20, 누락`에서 합계·평균·건수는 무엇을 뜻하는가? 누락을 0으로 보는 경우와 미확인으로 제외하는 경우는 다르다. 예제에 유일한 업무 정답을 만들지 말고 정의·가정에 따라 결과가 달라짐을 확인한다.

## 확인과 멈출 곳

자료 일부를 사람이 계산한 값·독립적인 자료와 대조한다. 행 수·중복·단위와 계산 근거를 남긴다. 자동 분석 보고서가 길다는 이유로 이해·품질을 인정하지 않는다. 현재 결정을 바꾸는 불확실성이 해소되거나 명시되면 불필요한 전수 분석을 늘리지 않는다.

합성 자료·추정·관측을 구분한다. 목표 수치에 맞춰 조정한 가정으로 같은 목표를 달성했다고 증명하지 않는다. 평가용 자료를 반복해서 보며 방법을 골랐다면 독립 평가로 남아 있는지 다시 판단한다. 추정 평균과 실제 반드시 지킬 한도를 같은 것으로 취급하지 않는다.
