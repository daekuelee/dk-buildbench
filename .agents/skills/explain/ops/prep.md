# explain prep — AI 없이 설명할 재료를 모은다

현재 안내에서 확인한 후속 문항 조건에 맞춰 준비한다. 형식·문항 수·시간·AI 사용 조건을 다른 회차에서 가져오지 않는다. 사용자가 실제로 한 일과 판단을 자기 말로 설명할 수 있도록 근거를 모은다.

## 근거를 읽는다
plan·decisions·questions·worklog·limits(있으면)와 관련 코드·git 기록을 읽는다. decisions가 연결한 원문을 재사용한다. docs/evals.md의 기대값·출처와 검증 결과·실행 로그를 함께 본다. 동작 경로가 불명확하면 요청 하나를 직접 확인한다. 실행하지 못한 것은 표시한다.
제출 문서의 주장을 코드와 대조해서, 문서와 구현이 다른 곳과 검증하지 않은 주장을 파일:줄로 보여 준다. 고치지는 않는다.

## docs/reports/prep.md를 쓴다
- 앱의 뼈대 한 문장과 필요한 구조 그림.
- 주요 결정과 사용자 이유·버린 대안. 기록이 없으면 없다고 쓴다.
- 실제 약점, 영향과 다음 검증.
- 바뀐 요구가 있으면 무엇이 바뀌었고 어디에 반영했는지.
- 후속 질문에 답할 재료의 위치(파일:줄). 필요하면 실제 작업에 맞는 예상 질문을 붙인다.

답 문장은 대신 쓰지 않는다. 사용자는 전제 확인, 한 일과 판단, 약점, 다음 검증을 자신의 말로 설명한다. 정해진 수를 채우려고 결정·약점·변경 사건을 만들지 않는다. 출력과 기록은 SKILL을 따른다.
