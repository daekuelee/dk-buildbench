# 설명 과정의 일반 점검 기준

특정 회차의 회고·사례 대신 재사용할 규칙만 남긴다. 현재 절차는 SKILL과 ops를 따른다.

- PROFILE의 익숙한 영역은 비유의 기준으로 쓰고 현재 낯선 연결을 설명한다.
- 질문의 답·선택 차이·추천 이유를 먼저 보여 준다. 파일에 상세 설명이 있어도 채팅에서 판단 근거를 숨기지 않는다.
- 부품 이름을 나열하는 대신 입력·변화·출력과 실패 경계를 연결한다.
- 새 낱말은 처음 등장할 때 정의한다. 읽은 코드와 실제 실행으로 확인한 동작을 구분한다.
- 그림·표·작은 사례는 질문에 필요한 것만 쓴다. 텍스트에서도 핵심 관계가 보여야 한다.
- 이해한 느낌이나 짧은 승인을 이해 증거로 쓰지 않는다. 중요한 선택에서 관찰된 적용만 기록하고 이미 확인한 것은 반복하지 않는다.
