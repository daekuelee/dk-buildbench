# 조사 과정의 일반 점검 기준

특정 회차의 회고·사례 대신 재사용할 규칙만 남긴다. 현재 절차는 SKILL과 ops를 따른다.

- 열어 보지 않은 자료를 읽었다고 쓰지 않는다. 관측·인용·추론·미확인을 구분한다.
- 지금 선택에 필요한 질문을 좁히고 근거가 충분하면 멈춘다. 보고서 분량·후보 개수·조사 시간을 성과로 삼지 않는다.
- 기존 확인은 조건이 맞으면 재사용한다. 다른 환경·다른 입력의 관측을 현재의 보장으로 쓰지 않는다.
- 필요한 출처와 웹 허락은 sources.md를 따른다. 같은 범위의 허락을 반복해서 받지 않는다.
- 읽기 전용 역할은 답을 반환하며 메인이 근거·채택을 기록한다. 조사 추천을 사용자 선택으로 기록하지 않는다.
